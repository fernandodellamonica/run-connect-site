RUN CONNECT · PRIVACY

Privacy Policy

This policy explains what information Run Connect handles, how a future Garmin Connect integration will use activity data, and the choices available to users.

Effective date: November 4, 2026

EnglishPortuguês (Brasil)

1. Project and contact

Run Connect is an independent, non-commercial learning and development project created by Fernando Della Monica Pereira, an individual developer based in Brazil. It is currently intended for personal and family use.

Privacy contact: runconnect@proton.me.

2. Information handled by Run Connect

Depending on the features used, Run Connect may handle:

  • Account information: email address and authentication identifiers used to sign in and associate records with the correct Run Connect account.
  • Run Connect activity information: activity date and time, activity type, distance, duration, pace, speed, elevation, splits, and GPS route information recorded by the app.
  • Garmin activity information (after the integration is enabled): activity details made available by Garmin through the Activity API, which may include activity type, date and time, distance, duration, performance metrics, and route or location details contained in the data Garmin provides.
  • Workout information: structured workouts, steps, targets, and training settings created or selected by the user in Run Connect.
  • Integration and synchronization information: Garmin account/API identifiers, permissions, record identifiers, synchronization status, timestamps, and technical markers needed to associate and synchronize records.

3. How Garmin data will be used

Garmin Connect integration is under development and is not currently active. No Garmin activity data is currently collected by Run Connect or sent to Garmin through this integration.

When the integration becomes available, a user will first choose to connect their Garmin Connect account and authorize the requested permissions through Garmin's OAuth consent process. Garmin Activity API data will then be associated with that identifiable user's Run Connect account, not treated as anonymous data.

The Activity API will be used to import the user's Garmin activities into their Run Connect activity history, display activity details, and support running history and performance features. Garmin's Starter Access delivers data by push and does not include historical data; the integration will process data made available by Garmin after the user's connection is authorized.

The Training API will be used in the opposite direction: Run Connect may send structured workouts created by the user to that user's Garmin Connect account so they can be synchronized to compatible Garmin devices. Workout content is not sold or used for advertising.

4. Storage, route privacy, and synchronization

Run Connect follows a local-first approach. Raw GPS trackpoints recorded by Run Connect are stored on the Android device. Core run recording is designed to work without an internet connection.

If the user enables Run Connect cloud synchronization, selected account, activity, split, workout, and integration information may be stored in the Run Connect backend. Route information may be simplified or privacy-processed before it is included in a synchronized record. The app's privacy-zone feature is designed to suppress route points around configured sensitive areas, such as activity start and finish locations. A route may be shortened, split into segments, or omitted.

Garmin-provided activity data will be processed only as needed to import and display the user's activities and provide the features described in this policy. The exact fields available depend on the Garmin API payload and the permissions granted by the user.

5. Third-party services and data sharing

Run Connect identifies the following services for the planned integration:

  • Garmin Connect / Garmin Developer Program: the integration partner and source of Garmin activity data. Garmin receives user authorization through its own consent flow. Run Connect sends user-created structured workouts to Garmin Connect when the Training API is enabled.
  • Supabase: the backend provider for account authentication, database storage, and cloud synchronization. The Run Connect Supabase project's primary region is East US (North Virginia), United States. If cloud synchronization is enabled, selected Garmin-derived activity and account-linked information may be stored there to provide Run Connect features.
  • GitHub Pages: hosts this static project website only. It is not intended to receive or process Garmin activity data.

Run Connect does not sell Garmin activity data or other personal information. Garmin-derived information is not shared with third parties for their own advertising, marketing, or independent commercial purposes. Supabase processes selected information as a service provider on behalf of Run Connect.

No third-party analytics, advertising, machine-learning, or AI service is currently planned to process Garmin-derived data.

6. AI and automated processing

Run Connect does not currently use AI systems, machine-learning models, or generative AI services to analyze, train on, evaluate, or improve models using Garmin-derived data. If this changes, this policy will be updated before the feature is introduced, and users will receive a clear notice and an appropriate choice before their Garmin data is processed by such a system.

7. User choices, access, and data requests

Connecting Garmin is optional. Users will be asked to authorize the connection and the requested data permissions before any Garmin data is exchanged. Users may withdraw Garmin sharing permissions through their Garmin Connect account. Run Connect will provide a way to disconnect the Garmin account in the app when the integration is released.

Users may request access to, correction of, or deletion of account-associated information, and may request an export or copy of their information, by emailing runconnect@proton.me from the email associated with their Run Connect account. Requests will be verified as reasonably necessary. Users may also manage Android location permissions through Android settings.

When a Garmin connection is disconnected or consent is withdrawn, Run Connect will stop requesting new Garmin data for that connection. The user may separately request deletion of Garmin-derived records already stored in Run Connect. Local device copies and cloud copies are separate and may need to be managed separately.

8. Retention and security

Local activity information remains on the device until it is deleted through the app or the relevant device data is removed. Cloud information is retained while needed to provide account and synchronization features, unless a valid deletion request is received. Technical synchronization markers may be used to prevent deleted records from reappearing during a later sync.

Run Connect uses account-based access controls and reasonable technical measures intended to protect information. No device, network, or storage method can be guaranteed to be completely secure. Deleting cloud information does not automatically delete a separate copy that remains on a device.

9. Changes and contact

This policy will be updated if the Garmin integration is activated or if the project's data practices or service providers change. The current version will be available at this URL.

For questions or privacy requests, contact runconnect@proton.me.
