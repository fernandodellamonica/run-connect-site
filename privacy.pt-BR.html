RUN CONNECT · PRIVACIDADE

Política de Privacidade

Esta política explica quais informações o Run Connect trata, como uma futura integração com o Garmin Connect utilizará dados de atividades e quais escolhas estarão disponíveis aos usuários.

Vigência: 4 de novembro de 2026

Português (Brasil)English

1. Projeto e contato

O Run Connect é um projeto independente e não comercial de aprendizado e desenvolvimento, criado por Fernando Della Monica Pereira, desenvolvedor pessoa física residente no Brasil. Atualmente, destina-se ao uso pessoal e familiar.

Contato sobre privacidade: runconnect@proton.me.

2. Informações tratadas pelo Run Connect

Dependendo dos recursos utilizados, o Run Connect poderá tratar:

  • Informações da conta: endereço de e-mail e identificadores de autenticação usados para entrar e associar registros à conta correta do Run Connect.
  • Informações de atividades gravadas pelo Run Connect: data e horário, tipo de atividade, distância, duração, ritmo, velocidade, elevação, parciais e informações de percurso GPS gravadas pelo aplicativo.
  • Informações de atividades Garmin (após a integração ser ativada): detalhes de atividades disponibilizados pela Garmin por meio da Activity API, que podem incluir tipo de atividade, data e horário, distância, duração, métricas de desempenho e informações de percurso ou localização presentes nos dados fornecidos pela Garmin.
  • Informações de treinos: treinos estruturados, etapas, metas e configurações de treinamento criados ou selecionados pelo usuário no Run Connect.
  • Informações de integração e sincronização: identificadores de conta/API Garmin, permissões, identificadores de registros, estado da sincronização, datas e marcadores técnicos necessários para associar e sincronizar registros.

3. Como os dados Garmin serão utilizados

A integração com o Garmin Connect está em desenvolvimento e ainda não está ativa. Atualmente, o Run Connect não coleta dados de atividades Garmin nem os envia à Garmin por meio dessa integração.

Quando a integração estiver disponível, o usuário deverá escolher conectar sua conta Garmin Connect e autorizar as permissões solicitadas pelo fluxo de consentimento OAuth da Garmin. Os dados fornecidos pela Garmin por meio da Activity API serão associados à conta identificável daquele usuário no Run Connect, e não tratados como dados anônimos.

A Activity API será utilizada para importar as atividades Garmin do usuário para o histórico de atividades do Run Connect, exibir detalhes das atividades e apoiar os recursos de histórico e métricas de desempenho. O Starter da Garmin entrega os dados por Push e não inclui dados históricos; a integração processará os dados disponibilizados pela Garmin após a autorização da conexão pelo usuário.

A Training API será utilizada na direção oposta: o Run Connect poderá enviar treinos estruturados criados pelo usuário para a conta Garmin Connect desse usuário, permitindo a sincronização com dispositivos Garmin compatíveis. O conteúdo dos treinos não será vendido nem utilizado para publicidade.

4. Armazenamento, privacidade de percursos e sincronização

O Run Connect segue uma abordagem local-first. Os pontos GPS originais gravados pelo Run Connect são armazenados no dispositivo Android. A gravação básica de corridas foi projetada para funcionar sem conexão com a internet.

Se o usuário habilitar a sincronização em nuvem do Run Connect, determinadas informações de conta, atividades, parciais, treinos e integração poderão ser armazenadas no backend do Run Connect. As informações de percurso poderão ser simplificadas ou processadas pelas regras de privacidade antes de serem incluídas em um registro sincronizado. O recurso de zonas de privacidade foi projetado para suprimir pontos próximos a áreas sensíveis configuradas, como locais de início e fim da atividade. Um percurso poderá ser encurtado, dividido em segmentos ou omitido.

Os dados de atividades fornecidos pela Garmin serão processados somente na medida necessária para importar e exibir as atividades do usuário e fornecer os recursos descritos nesta política. Os campos exatos disponíveis dependem do conteúdo enviado pela API Garmin e das permissões concedidas pelo usuário.

5. Serviços de terceiros e compartilhamento de dados

O Run Connect identifica os seguintes serviços para a integração planejada:

  • Garmin Connect / Garmin Developer Program: parceiro de integração e fonte dos dados de atividades Garmin. A Garmin recebe a autorização do usuário por meio de seu próprio fluxo de consentimento. O Run Connect envia treinos estruturados criados pelo usuário ao Garmin Connect quando a Training API estiver habilitada.
  • Supabase: fornecedor de backend para autenticação de contas, armazenamento em banco de dados e sincronização em nuvem. A região primária do projeto Supabase do Run Connect é East US (North Virginia), Estados Unidos. Quando a sincronização em nuvem estiver habilitada, determinadas informações de atividades derivadas da Garmin e vinculadas à conta poderão ser armazenadas ali para fornecer os recursos do Run Connect.
  • GitHub Pages: hospeda somente este site estático do projeto. Não se destina a receber ou processar dados de atividades Garmin.

O Run Connect não vende dados de atividades Garmin nem outras informações pessoais. As informações derivadas da Garmin não são compartilhadas com terceiros para publicidade, marketing ou finalidades comerciais independentes desses terceiros. O Supabase processa determinadas informações como prestador de serviços em nome do Run Connect.

Atualmente, não está previsto o uso de serviços de analytics, publicidade, aprendizado de máquina ou inteligência artificial de terceiros para processar dados derivados da Garmin.

6. Inteligência artificial e processamento automatizado

O Run Connect atualmente não utiliza sistemas de inteligência artificial, modelos de aprendizado de máquina ou serviços de IA generativa para analisar dados derivados da Garmin, treinar, avaliar ou aprimorar modelos com esses dados. Caso isso mude, esta política será atualizada antes da introdução do recurso, e os usuários receberão um aviso claro e uma opção apropriada antes que seus dados Garmin sejam processados por tal sistema.

7. Escolhas do usuário, acesso e solicitações sobre dados

A conexão com a Garmin é opcional. Antes de qualquer troca de dados Garmin, o usuário deverá autorizar a conexão e as permissões solicitadas. O usuário poderá retirar as permissões de compartilhamento Garmin por meio de sua conta Garmin Connect. Quando a integração for disponibilizada, o Run Connect fornecerá uma opção para desconectar a conta Garmin no aplicativo.

O usuário poderá solicitar acesso, correção ou exclusão de informações associadas à conta, bem como solicitar uma cópia ou exportação de suas informações, enviando um e-mail para runconnect@proton.me a partir do endereço associado à conta Run Connect. As solicitações serão verificadas quando razoavelmente necessário. As permissões de localização do Android também podem ser gerenciadas nas configurações do sistema.

Quando uma conexão Garmin for desconectada ou o consentimento for retirado, o Run Connect deixará de solicitar novos dados Garmin daquela conexão. O usuário poderá solicitar separadamente a exclusão dos registros derivados da Garmin que já estejam armazenados no Run Connect. Cópias locais no dispositivo e cópias em nuvem são separadas e poderão precisar ser gerenciadas separadamente.

8. Retenção e segurança

As informações de atividades armazenadas localmente permanecem no dispositivo até serem apagadas pelo aplicativo ou até que os dados correspondentes do dispositivo sejam removidos. As informações em nuvem são mantidas enquanto forem necessárias para fornecer os recursos de conta e sincronização, salvo quando houver uma solicitação válida de exclusão. Marcadores técnicos de sincronização poderão ser utilizados para impedir que registros apagados reapareçam em uma sincronização posterior.

O Run Connect utiliza controles de acesso por conta e medidas técnicas razoáveis destinadas a proteger as informações. Nenhum dispositivo, rede ou método de armazenamento pode ter segurança total garantida. A exclusão de informações em nuvem não apaga automaticamente uma cópia separada que permaneça no dispositivo.

9. Alterações e contato

Esta política será atualizada se a integração Garmin for ativada ou se as práticas de tratamento de dados ou os prestadores de serviço do projeto forem alterados. A versão atual ficará disponível neste endereço.

Para dúvidas ou solicitações relacionadas à privacidade, entre em contato pelo endereço runconnect@proton.me.
